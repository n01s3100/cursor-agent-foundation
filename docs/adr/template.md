# ADR template

Copy this file to `docs/adr/NNNN-short-slug.md` (four-digit number, increment from highest existing ADR).

Full criteria: [skills/engineering/grill-with-docs/ADR-FORMAT.md](../../skills/engineering/grill-with-docs/ADR-FORMAT.md).

---

## Minimal (preferred)

```markdown
# Short title of the decision

One to three sentences: context, what we decided, and why.
```

## With optional sections (use only when they add value)

```markdown
# ADR-NNNN: Title

**Status:** accepted

**Context:** …

**Decision:** …

**Consequences:** … (non-obvious downstream effects only)

**Considered options:** … (only when rejections are worth remembering)
```

Numbering: scan `docs/adr/` for the highest `NNNN` and add one.
